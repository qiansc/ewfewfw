# Part 03.5: MCP 包架构清理与命名规范化

> 详细执行计划 - 对齐 `v0.3.0/architecture.md` 知识生命周期设计

---

## 背景

当前代码结构与设计文档存在偏差，MCP Server 命名混乱：

### 问题 1: 包结构不规范

| 问题 | 现状 | 设计要求 |
|------|------|----------|
| Store MCP 位置错误 | `packages/cli/src/mcp/store/` | 独立包 `packages/mcp-store/` |
| Code MCP 命名不符 | `packages/mcp-code/` | 按知识生命周期应为 `mcp-extract` |
| 遗留包未清理 | `packages/mcp-data/` (Python) | 已废弃，应删除 |
| 遗留包未清理 | `packages/mcp-dsl/` | 已迁移到 storage，应删除 |

### 问题 2: MCP Server 命名混乱

**现状**（`.claude/settings.json` 中的工具名）：
```
mcp__c4a-dsl-mcp__c4a_store_save
mcp__c4a-dsl-mcp__c4a_store_read
mcp__c4a-dsl-mcp__c4a_store_feat_lifecycle
mcp__c4a-dsl-mcp__c4a_query_search
mcp__c4a-code-mcp__c4a_code_extract
mcp__c4a-visual-mcp__c4a_visual_generate
```

**问题分析**：
- `c4a-dsl-mcp` 是历史遗留名称，应该改为 `c4a-store-mcp` 或 `c4a-query-mcp`
- Store 和 Query 工具混在同一个 Server (`c4a-dsl-mcp`) 中
- `c4a-code-mcp` 应改为 `c4a-extract-mcp`

**目标命名规范**：

| MCP Server | 工具前缀 | 工具名示例 |
|------------|----------|-----------|
| `c4a-extract-mcp` | `c4a_extract_*` | `c4a_extract_interfaces`, `c4a_extract_analyze` |
| `c4a-store-mcp` | `c4a_store_*` | `c4a_store_save`, `c4a_store_read` |
| `c4a-query-mcp` | `c4a_query_*` | `c4a_query_search`, `c4a_query_deps` |
| `c4a-visual-mcp` | `c4a_visual_*` | `c4a_visual_generate` (已规范 ✅) |

**知识生命周期（architecture.md §1.3）**：

```
Extract → Model → Store → Query
   ↓        ↓       ↓       ↓
mcp-extract  -   mcp-store mcp-query
```

## MCP Server 命名规范

### 命名规则

| 组件 | 命名规则 | 示例 |
|------|----------|------|
| NPM 包名 | `@c4a/mcp-{lifecycle}` | `@c4a/mcp-extract` |
| MCP Server Name | `c4a-{lifecycle}-mcp` | `c4a-extract-mcp` |
| 工具名 | `c4a_{lifecycle}_{action}` | `c4a_extract_interfaces` |
| 目录路径 | `packages/mcp-{lifecycle}/` | `packages/mcp-extract/` |

#### Extract 工具 (c4a_code_* → c4a_extract_*)
