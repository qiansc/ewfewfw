# v0.3.0 (2026-02-03)

重大架构升级：引入三模式架构（Local/Server/Remote）、Feat 分支机制、完整的 CLI 工具链。

## Added

### 三模式架构
- **Local 模式**：SQLite + USearch (WASM)，零依赖本地运行
- **Server 模式**：MongoDB + Neo4j + Milvus，团队协作
- **Remote 模式**：连接远程 Server 实例，本地仅 CLI
- 模式切换与数据迁移支持（`c4a install --mode=<mode>`）

### 存储层重构
- **@c4a/storage 包**：独立的存储适配层
  - `StorageAdapter` 接口：统一 Local/Server 访问
  - `LiteAdapter`：SQLite 实现（Local 模式）
  - `ServerAdapter`：HTTP 客户端（Server/Remote 模式）
- **SQLite Schema**：实体表、关系表、向量表、历史表
- **USearch 向量搜索**：WASM 实现，无需外部依赖
- **storage-backend**：Python FastAPI 后端（Server 模式）

### Feat 分支机制
- 类似 Git 分支的知识隔离机制
- Feat 生命周期管理：`create → transition → merge → delete`
- Checklist 任务追踪
- 并发修改检测与冲突解决

### MCP 工具重构
- **mcp-store**（15 个工具）：
  - CRUD：`c4a_store_save`、`c4a_store_read`、`c4a_store_list`、`c4a_store_delete`
  - 同步：`c4a_store_sync`、`c4a_store_plan_sync`
  - Feat：`c4a_store_feat_lifecycle`、`c4a_store_feat_merge`、`c4a_store_feat_checklist`
  - 工具：`c4a_store_validate`、`c4a_store_backup`、`c4a_store_restore`、`c4a_store_repair`
  - 历史：`c4a_store_read_history`、`c4a_store_update_workflow_step`
- **mcp-query**（3 个工具）：
  - `c4a_query_search`：语义搜索
  - `c4a_query_deps`：依赖查询
  - `c4a_query_impact`：影响分析
- **mcp-extract**（4 个工具）：保持不变

### CLI 工具链
- **用户 CLI**（@c4a/cli）：
  - `c4a init`：初始化项目
  - `c4a install`：安装并配置工作模式
  - `c4a sync`：同步知识到数据库
  - `c4a status`：查看状态
  - `c4a validate`：验证 DSL 文件
  - `c4a feat`：Feat 分支管理
- **开发者 CLI**（@c4a/cli-dev）：
  - 交互式菜单界面（Ink）
  - Docker 服务管理
  - MCP 服务调试
  - `build` 命令：构建和依赖检查

### Skills 系统
- **工作流 Skills**（5 个）：
  - `/c4a:feat`：Feature 管理
  - `/c4a:specify`：功能规格（Functional Spec）
  - `/c4a:plan`：技术方案（Technical Spec）
  - `/c4a:analyze`：一致性检查
  - `/c4a:implement`：代码实现辅助
- **知识技能 Skills**（2 个）：
  - `/c4a:know:learn`：快速录入知识
  - `/c4a:know:search`：搜索知识库
- 模块化 SKILL.md 结构

### 数据操作模块
- **事务管理**：跨实体原子操作
- **工作流恢复**：断点续传
- **交叉引用检查**：引用完整性验证
- **同步导出**：增量/全量同步

### 安全增强
- DSL 注入防护
- 路径安全检查（禁止绝对路径、父目录引用）
- 错误响应规范（错误码、可恢复操作）

### 知识模型扩展
- **8 种实体类型**：System、Container、Component、ADR、Contract、Product、Process、SoR
- **知识点类型（kind）**：`implementation`、`external`、`concept`
- **双视角三构建块**模型

## Changed

### 架构重构
- MCP 工具重命名：`legacy_*` → `c4a_store_*`
- 存储层从 mcp-dsl 提取为独立 @c4a/storage 包
- CLI 拆分为用户 CLI 和开发者 CLI
- 配置系统统一到项目根目录

### 目录结构
- 知识存储目录：`.c4a/` → `.context/`
- 子目录：`drafts/`、`approved/`、`published/`、`archive/`

### 状态流转
- 简化为：`draft → approved → published → deprecated → archived`
- 移除 `implemented` 状态

- **mcp-data 包**：功能合并到 @c4a/storage
- **旧版 MCP 接口**：`c4a_local_*` 系列工具
- **prompts/AGENTS.md**：内容合并到 CLAUDE.md
