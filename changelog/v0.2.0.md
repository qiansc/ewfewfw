# v0.2.0 (2026-01-15)

C4A 首个功能完整版本，建立 MCP 架构和知识管理基础。

## Added

### 核心架构
- **MCP 服务架构**：基于 Model Context Protocol 的三服务设计
  - `mcp-code`：代码分析服务（AST 解析、接口提取、契约生成）
  - `mcp-dsl`：DSL 管理服务（验证、存储、状态流转）
  - `mcp-data`：数据服务（MongoDB、Neo4j、Milvus 集成）
- **C4A DSL**：基于 C4 模型的架构描述语言（`.c4a.yaml`）
- **知识状态流转**：`draft → approved → published → deprecated → archived`

### MCP 工具
- `c4a_extract_interfaces`：从代码提取接口定义
- `c4a_extract_analyze`：分析代码结构和依赖
- `c4a_extract_ast`：获取 AST 结构
- `c4a_extract_contract`：生成 API 契约（OpenAPI/AsyncAPI/Proto）
- `c4a_local_*`：本地 DSL 文件操作（init/list/read/write/transition）
- `c4a_store_sync`：同步 DSL 到知识库

### CLI 工具
- `start.sh`：交互式启动脚本
- 开发模式（dev）：本地 MCP + Docker 存储
- 生产模式（prod）：全容器化部署
- Docker Desktop 自动启动检测

### 可视化服务
- `mcp-visual`：知识可视化 MCP 服务
- Gemini API 集成用于图片生成
- C4 架构图渲染（Mermaid）

### Agent Prompts
- `prompts/c4a.md`：默认 Agent prompt
- `prompts/AGENTS.md`：Agent 行为规则
- ADR 工作流 Skills：`c4a-adr-draft`、`c4a-adr-review`、`c4a-adr-status`
- 研究 Skill：`c4a-research`

### 配置生成器
- `config-generator`：为不同 AI 平台生成 MCP 配置
- 支持 Claude Desktop、Cursor、Windsurf、OpenCode 等

### 架构知识（自举）
- ADR-001：v2 架构设计
- ADR-002：DSL Schema 设计
- ADR-003：MCP 架构设计
- ADR-004：知识覆盖完整性
- ADR-005：引入 mcp-visual 服务
- 完整的 System/Container/Component DSL 定义
