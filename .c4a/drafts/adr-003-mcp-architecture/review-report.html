3.3 双模式传输

⚡ 开发模式 (Stdio)
  • Agent 通过 stdin/stdout 通信
  • MCP Server 作为子进程运行
  • 启动快，无需网络配置
  • 适用：本地开发
🐳 部署模式 (HTTP)
  • Agent 通过 HTTP 请求通信
  • MCP Server 作为 Docker 容器运行
  • 可横向扩展，集中管理
  • 适用：生产部署

切换方式: 设置环境变量 MCP_TRANSPORT=stdio|http

结果: ✅ 3 个容器全部验证通过
问题 3: c4a-code-mcp 缺少依赖关系
原因: 遗漏了与 c4a-core 的依赖声明
修复: 添加 relationships → c4a-core
结果: ✅ 依赖关系完整
问题 4: ADR 内容过于具体
原因: 包含具体端口号、启动命令等实现细节
修复: 端口号改为 "各服务独立端口"；启动命令移至容器 knowledge.how
